# Scripts Directory

ここは `core-service` リポジトリの品質を担保し、開発効率を上げるための **「開発補助ツール（CIツール）」専用のディレクトリ** です。

> [!WARNING]
> **本番ジョブ配置禁止の原則**
> AI業務として実行される本番用スクリプトや定期バッチ処理をここに配置することはアーキテクチャルールで禁止されています。（それは `agent-core` の責務です。詳細は `docs/architecture.md` を参照）

## スクリプト一覧（インデックス）

以下のスクリプト群が提供されています。
各スクリプトの詳細仕様は、それぞれのファイル内のDocStringを参照してください。

- `validate_sdd.py`: テストの仕様ID（SDD）紐付けやアーキテクチャ構造を自動検証するLinter。

---
※ **仕組み化**: 新しいスクリプトを追加した場合は、必ずこの一覧に追記してください。記載漏れは `validate_sdd.py` によって検知され、エラーとなります。
