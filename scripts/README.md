# Scripts Directory

ここは `core-service` リポジトリの品質を担保し、開発効率を上げるための **「開発補助ツール（CIツール）」専用のディレクトリ** です。

> [!WARNING]
> **本番ジョブ配置禁止の原則**
>## 🚫 配置禁止なもの
- 「定期バッチ実行用のスクリプト」
- 「本番環境へのデプロイやマイグレーションを実行するスクリプト」
  （それらは上位レイヤー（オーケストレーター）の責務です。`core-service` はあくまでインポートされる側のステートレスなライブラリとして存在します）

## Scripts

各種バッチや管理用スクリプトを格納するディレクトリ。

- `seed_tasks.py`: （非推奨/削除予定）SQLite DBを初期化し、既存のYAML等の情報を元にテスト・初期データを投入するスクリプト。
- `seed_recurring_tasks.py`: DBスキーマ変更に伴う、新しい定期タスク構造の初期データ投入スクリプト。
- `validate_sdd.py`: SDD (Spec-Driven Development) に基づき、テストコードに仕様IDが正しく付与されているか、Mockが使われていないか等のアーキテクチャ制約を検証する静的解析スクリプト。
- `setup_db.py`: SQLiteデータベースを初期化・作成する。
- `batch_daily_scheduler.py`: 毎日のタスク計画をバッチ処理で自動生成する。
- `sync_calendar.py`: 生成されたタスク計画をカレンダーに同期する。

---
※ **仕組み化**: 新しいスクリプトを追加した場合は、必ずこの一覧に追記してください。記載漏れは `validate_sdd.py` によって検知され、エラーとなります。
