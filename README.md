# core-service

You_Inc エコシステムにおける「情報システム部（工場）」リポジトリです。

Agentの状態(State)を一切持たず、副作用(外部APIやDB)をカプセル化したステートレスで堅牢なドメインロジック/APIを提供するサービスです。
実際のビジネスロジックはすべてここに集約されます。

## 開発環境と実行（Agent駆動）
本リポジトリはパッケージマネージャとして **`uv`** を使用しています。
また、AIエージェントおよび人間がコマンドの差異を意識せず実行できるよう、**`Makefile`** でタスクを抽象化しています。

- **セットアップ**: `make setup` (内部で `uv sync` を実行)
- **テスト実行**: `make test` (内部で `uv run pytest` を実行)
- **静的解析**: `make lint` (内部で `uv run ruff` を実行)
- **アーキテクチャ検証**: `make validate` (内部でLinterを実行)
- **全検証実行**: `make check-all`
